## ШАГ 1. Аудит категории УПА

### 1.1. Определение и границы

| Параметр | Значение | Источник |
|----------|----------|----------|
| Расшифровка | Установка пожаротушения автономная | СП 486.1311500.2020 (изм. №1), СП 485.1311500.2020 |
| Определение (ТР ЕАЭС 043/2017) | АУП, функционирующая **независимо от внешних источников питания и систем управления** и обеспечивающая **передачу сигнала о пожаре во внешние цепи** | ТР ЕАЭС 043/2017 |
| Ключевой вывод из определения | УПА = и **автономная** (самообнаружение + тушение), и **автоматическая** (сигнал во внешние цепи / СПА) | Разбор нормативных публикаций |
| Когда вместо АУП | «В специально оговоренных по тексту СП 486 случаях» | п. 1.1 СП 486 |
| Типичные объекты | Электрощиты и электрошкафы (в т.ч. РУ) объёмом **≥ 0,03 м³**; локальная защита оборудования АСУ ТП при наличии СПС в помещении | табл. 3–4 СП 486, примечания |

### 1.2. Найденные ошибки и нестыковки (рынок / норматив / позиция УГП-Авт)

| № | Тип | Где | Суть | Предлагаемое исправление |
|---|-----|-----|------|--------------------------|
| 1 | Путаница терминов | Сайт, КП, презентации | «УПА» = категория норм; у конкурентов «УПА» / «УПА-Г» = торговые линейки; у нас бренд — **УГП-Авт** | В материалах: «УГП-Авт — газовая УПА для шкафов/объёмов …» + отдельный блок «что такое УПА по СП» |
| 2 | Нормативный разрыв | СП 485 до 01.01.2026 | До изм. №1 требований к УПА в СП 485 почти не было; с **01.01.2026** — раздел 13 (СТО для негазовых, состав ПД, сертификация, класс опасности ОТВ) | Актуализировать «нормативный блок» брошюры/презентации под СП 485 изм. №1 |
| 3 | Исключение для газовых | п. 13.3 СП 485 | СТО, согласованные с МЧС, требуются при проектировании УПА **за исключением газовых** | Для УГП-Авт (газ) акцент на ТР ЕАЭС / СТО компании / ВНИИПО, а не на «обязательный реестр СТО МЧС» как единственный критерий |
| 4 | СТО в реестре МЧС | Публичные обзоры | На дату обзоров фиксировалось, что согласованных СТО по УПА в реестре МЧС может не быть | Не заявлять «все конкуренты уже с СТО МЧС»; проверять реестр перед каждым тендером |
| 5 | Порог объёма шкафа | СП 486 табл. 4 | Защита от **0,03 м³** — это ~30 л; линейка УГП-Авт-П стартует с **1 м³** | Явно сегментировать: малые щиты (0,03–1 м³) vs средние/крупные объёмы; для малых — партнёрский / отдельный SKU (идея в Блоке 4) |
| 6 | Сигнал во внешние цепи | Определение УПА | Без передачи сигнала изделие **не попадает** под определение УПА ТР ЕАЭС | В карточках УГП-Авт держать реле давления / вывод сигнала как **обязательный** атрибут категории, не «опцию для красоты» |
| 7 | Температура обнаружения | Конкуренты vs УГП-Авт | У части конкурентов колба **57 °C** / трубки ~90–150 °C; у УГП-Авт трубка **140±10 °C** (+ опция УПТЗ-57) | Готовый слайд «почему 140 °C + когда 57 °C»; без обесценивания, с нормативной аргументацией |
| 8 | Срок службы | Паспорт П-Х-1 vs рынок | У УГП-Авт-П-Х-1 в данных — **12 мес.**; у УПА-Г / F-Line заявлено **~10 лет** | Либо уточнить паспорт/переосвидетельствование, либо честно вынести в W и план продукта |
| 9 | Единицы измерения | Сравнения | м³, литры модуля, кг ГОТВ смешиваются | Единый шаблон: объём защиты (м³) + вместимость (л) + масса ГОТВ (кг) |
| 10 | Дублирование брендов | Рынок | «УПА AFESPRO», «УПА-Г» (НТО Пламя), категория УПА в СП | В конкурентной карте разделять **категорию** и **торговые имена** |

### 1.3. Что исключить из позиционирования УГП-Авт как УПА

| Исключить | Причина |
|-----------|---------|
| Утверждение «любая автономная установка = УПА» без сигнала во внешние цепи | Не соответствует ТР ЕАЭС 043/2017 |
| Позиционирование УГП-Авт-К (CO₂) для помещений с постоянным пребыванием людей без отдельной методики | Риски безопасности и возражения проектировщиков |
| Обещание «не требует проекта» как универсальное | Для части сценариев (УПА-Г-У, локальная защита помещений) проектирование/расчёт по СП 485 обязателен |
| Сравнение только по цене без объёма и ГОТВ | Искажает тендерные таблицы |
| П+CO₂ и К+хладон/ФК в материалах УПА-сегмента | Запрещены коммюнике 11.08.2026 |

### 1.4. Вердикт аудита

Категория УПА **нормативно оформлена** (СП 486 изм. №1 + СП 485 изм. №1 с 01.01.2026) и создаёт **обязательный спрос** на защиту электрощитов/шкафов. Данных достаточно для SWOT, конкурентной карты и дорожной карты сегмента. **Недостаточно** для точного TAM/SAM в рублях и штуках без отдельного исследования (в источниках есть качественные драйверы, но нет утверждённой оценки рынка).

## ШАГ 2. SWOT (категория УПА → позиция УГП-Авт)

### Сильные стороны (S)

- УГП-Авт закрывает ключевые признаки УПА: энергонезависимость + реле давления / сигнал во внешние цепи.
- СТО 75562916-001-2025 с ВНИИПО и заключение ВНИИПО (13.07.2025) — аргумент для проектировщиков.
- Два принципа: **П** (прямое, хладон/ФК) и **К** (косвенное, CO₂) после коммюнике 11.08.2026.
- Склад 200 комплектов — готовность к отгрузке в Q4 2026.
- «Сделано в России», сертификаты ТР ЕАЭС (по базе УГП-Авт).

### Слабые стороны (W)

- Бренд «УГП-Авт» слабее категорийного запроса «УПА» / «пожаротушение электрошкафов».
- Нижняя граница объёма линейки П (1 м³) выше порога нормы 0,03 м³ — дыра на массовых малых щитах.
- Срок службы П-Х-1 = 12 мес. vs ~10 лет у лидеров категории.
- Температура трубки 140 °C vs маркетинговые 57 °C у части конкурентов.
- Материалы и сайт УГП-Авт ещё не синхронизированы с линейкой и с языком категории УПА (см. отчёт 18.08).

### Возможности (O)

- Нормативный драйвер: табл. 4 СП 486 — УПА вместо АУП для электрощитов/шкафов ≥ 0,03 м³.
- Локальная защита АСУ ТП (прим. к табл. 3) — вход в промышленные объекты без полной АУП помещения.
- Рост категорийных запросов («автономное газовое пожаротушение» — сильный рост в собранных ранее данных УГП).
- Окно каналов: Авито / Secumarket / Пульс цен / дилеры Эпотос и F-Line.
- Партнёрство на малых объёмах (0,03–1 м³) + собственный фокус на 1–7 м³.

### Угрозы (T)

- Зрелые игроки категории: **УПА-Г** (НТО Пламя), **УПА AFESPRO**, **F-Line**, **Парабола**, **АУП-01Ф**, **УГП Эол**.
- УПА-Г: широкий ряд 0,03–18 м³, до 7 ГОТВ, монтаж «5 минут», срок 10 лет.
- AFESPRO: язык «УПА» в SEO + проект/монтаж под ключ + модули от 0,25 л.
- Зависимость от импортного ГОТВ (хладон/ФК).
- Нормативная неопределённость по СТО/практике применения СП 485 в 2026 — возражения ГПН на объектах.

## ШАГ 5. Система сбора идей (фокус УПА)

### Источники

1. Возражения ГПН / проектировщиков по СП 485–486  
2. Тендеры на «УПА» / «пожаротушение электрошкафов»  
3. Конкуренты (новые объёмы, 57 °C, магнитный монтаж, СТО)  
4. Щитовики и интеграторы АСУ ТП  
5. Техподдержка (монтаж, ложные срабатывания, сигнал в СПА)  
6. Дилеры F-Line / Эпотос / региональные сети  

### Поля реестра

| Поле | Описание |
|------|----------|
| Название | Краткое имя |
| Источник | См. список выше |
| Сегмент УПА | Малые щиты / ЦОД / АСУ ТП / транспорт / склады / иное |
| Потенциал | 1–5 |
| Сложность | 1–5 |
| Бюджет | ₽ или «не оценено» |
| Приоритет | Высокий / средний / низкий |
| Статус | Новая → … → внедрена / отклонена |

### Методика рыночного потенциала (5 шагов)

1. **Объём спроса** — число объектов/шкафов в сегменте (только с источниками).  
2. **Конкуренты** — кто уже закрывает как «УПА», цены, сертификация.  
3. **Стоимость разработки** — КБ, испытания, склад, маркетинг.  
4. **ROI** — выручка × маржа − затраты.  
5. **Решение** — go / hold / kill (продукт + финансы).

## ШАГ 7. Вердикт

### Красный сценарий

Материалы остаются про «УГП-Авт» без языка категории УПА; малые щиты отданы AFESPRO/УПА-Г; возражения по 57 °C и сроку службы не закрыты.  
**Итог:** доля в категорийных тендерах низкая, склад 200 не закрыт.

### Жёлтый (базовый)

## Приложение A. Нормативный минимум для продаж

1. **УПА** = автономная АУП + сигнал во внешние цепи (ТР ЕАЭС 043/2017).  
2. Вместо АУП — только где прямо сказано в СП 486.  
3. Электрощиты/шкафы ≥ 0,03 м³ — ключевой кейс табл. 4.  
4. АСУ ТП: локальная УПА + СПС в помещении может заменить АУП на всё помещение (прим. табл. 3).  
5. С 01.01.2026 — раздел 13 СП 485: для **негазовых** УПА — СТО с МЧС; для газовых — акцент на сертификацию и ПД.  
6. В КП всегда: состав, алгоритм, ГОТВ, расчёт/объём, безопасность людей, удаление ГОТВ, контроль техсостояния.
