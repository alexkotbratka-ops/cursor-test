## ШАГ 2. SWOT-анализ

### Сильные стороны (S)

- Энергонезависимость (без внешнего питания).
- СТО 75562916-001-2025 с ВНИИПО и заключение ВНИИПО от 13.07.2025.
- Два принципа: прямое (П) и косвенное (К) действие.
- Реле давления / вывод сигнала во внешние цепи (подтверждено брошюрой).
- Статус «Сделано в России», сертификаты ТР ЕАЭС (по базе знаний).
- Склад 200 комплектов — готовность к отгрузке.
- Чёткое разделение ГОТВ после коммюнике снижает путаницу в продажах.

### Слабые стороны (W)

- Ошибочная страница на сайте (дубликат МПТИ) — репутационный и SEO-риск.
- Цены в целом не утверждены (кроме факта КП на П-Х-1).
- Срок службы П-Х-1 = 12 месяцев при заявленных у конкурентов 10–15 лет — уязвимость в сравнении.
- Температура эксплуатации от 0 °C (у части конкурентов ниже).
- Неполный публичный реестр артикулов/масс.
- Брошюра и презентации ещё не синхронизированы с новой линейкой.
- Узнаваемость брендового запроса «УГП-Авт» низкая (единицы запросов по Вордстат в базе).

### Возможности (O)

- Нормативный драйвер: СП 486 / изменения по УПА — защита электрошкафов.
- Рост категорийных запросов («автономное газовое пожаротушение» +314% в собранных данных).
- Окно на площадках: продукта нет на Авито / Secumarket / Пульс цен (по анализу в базе).
- Дилерские сети конкурентов (Эпотос, F-Line) как канал партнёрства.
- Сегменты: щитовики, ЦОД/стойки, транспорт, склады, проектировщики, монтажники МЧС.
- Система сбора идей до конца сентября — pipeline на 2027.

### Угрозы (T)

- Сильные прямые аналоги: F-Line, УПА-Г (до 16 м³), AFESPRO (57 °C + проектирование), Парабола (низкая цена), АУП-01Ф.
- Зависимость отрасли от импортного ГОТВ (хладон/ФК).
- Риск ложных ожиданий по замку 57 °C у конкурентов vs трубка 140 °C — нужна аккуратная нормативная аргументация.
- Просроченные обязательства по сайту и материалам снижают доверие внутренних стейкхолдеров.
- Агрессивный план склада (200 шт. до 31.12.2026) при незакрытой подготовке.

## ШАГ 5. Система сбора идей (первая итерация)

### Источники идей

1. Клиенты (возражения, запросы по ТЗ)  
2. Менеджеры продаж  
3. Конкуренты (новые SKU, цены, опции 57 °C, магнитный монтаж)  
4. Выставки и форумы  
5. Техподдержка (отказы, монтажные проблемы)  
6. Проектировщики / дилеры  

### Формат хранения (поля)

| Поле | Описание |
|------|----------|
| Название | Краткое имя идеи |
| Источник | Клиент / продажи / конкурент / выставка / техподдержка / иное |
| Рыночный сегмент | ЦОД / нефтегаз / транспорт / склады / щиты / иное |
| Оценка потенциала | Шкала 1–5 |
| Сложность реализации | Шкала 1–5 |
| Примерный бюджет | ₽ или «не оценено» |
| Приоритет | Высокий / средний / низкий |
| Статус | Новая / в анализе / в бэклоге / в разработке / отклонена / внедрена |

### Методика анализа рыночного потенциала (5 шагов)

1. **Оценка объёма рынка** — сегмент, число объектов/шкафов, доля УПА (только с источниками).  
2. **Анализ конкурентов** — кто закрывает потребность, цены, сертификация.  
3. **Оценка стоимости разработки** — КБ, сертификация, склад, маркетинг.  
4. **Расчёт ROI** — выручка × маржа − затраты; срок окупаемости.  
5. **Принятие решения** — go / hold / kill; фиксирует утверждающий (продукт + финансы).

**Дедлайн внедрения реестра:** не позднее 30.09.2026.  
**Ответственный за систему:** продукт; консультанты — маркетинг, продажи, техподдержка, финансы.

## ШАГ 7. Итоговый вердикт

### Пессимистичный (красный)

Страница и брошюра долго остаются несинхронизированными; цены не утверждают; обучение продаж формальное; конкуренты (F-Line, УПА-Г, AFESPRO) забирают дилеров.  
**Итог к 31.12.2026:** отгрузка ≪ 100 шт., склад затоваривается, срыв плана 200, потеря доверия к запуску УГП-Авт.

### Реалистичный (жёлтый)

Блок 1–2 закрыты в срок; техподдержка принимает продукт; 1–2 приоритетных сегмента и дилерский канал дают основной объём; идея-система запущена к концу сентября.  
**Итог:** ~150–200 шт. к 31.12.2026 при жёстком контроле KPI; выручка зависит от утверждённого прайса (ориентир из планов в данных — порядка нескольких млн ₽ при средних чеках из гипотез плана, **без принятия неподтверждённых средних цен как факта**).
