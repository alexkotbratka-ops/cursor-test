# УГП-Авт — перепроверенная структура дорожной карты

**Дата:** 18.08.2026  
**Фокус:** структура дорожной карты (ШАГ 4)  
**Правило:** только роли; без ФИО; без домыслов; пробелы — «требует заполнения»

---

## 0. Что было ошибочно в предыдущей версии

| Ошибка | Почему ошибочно | Как исправлено |
|--------|-----------------|----------------|
| Помесячный план продаж (сент. 35–45 и т.д.) подан как ориентир | В данных руководства есть только **200 шт. до 31.12.2026**; помесячка — из неподтверждённого ИИ-плана архива | Убрана из дорожной карты как факт. План Q4/Q1 — **выход Блока 3**, не вход |
| KPI: «≥7 слайдов», «≥80% обучены», «≥10 вопросов», «≥10 шт. в сентябре» | Цифры **не заданы** в инструкции и в исходных данных | KPI привязаны к **сдаваемым артефактам и датам**, без выдуманных порогов |
| Совещание: 01–02.09.2026 | В 2026 это **вт–ср**, не пн–вт | Корректно: **пн–вт после недели презентации → 31.08–01.09.2026** |
| Заполненные ТТХ по всем 9 SKU | Полные данные только по **П-Х-1** | Остальное — «требует заполнения» (Блок 1) |
| Выручка / средние чеки | Цены в целом **не утверждены** (кроме КП на П-Х-1) | Не входят в структуру дорожной карты |

## 1. Жёсткие рамки (только подтверждённое)

| Параметр | Значение |
|----------|----------|
| Склад | 200 комплектов |
| Цель | 200 шт. до 31.12.2026 |
| Линейка (коммюнике 11.08.2026) | **П** = хладон 227еа / ФК-5-1-12; **К** = только CO₂ |
| Модели | П-Х-1/2, П-ФК-1/2, К-У-0,7/1,4/2,1/3,5/7,0 |
| Полный паспорт в данных | только **УГП-Авт-П-Х-1** (арт. А635165.036-ПХ.01; 1 м³; 1 кг; трубка 4 м в комплекте; КП 43 588 ₽ с НДС 22%) |
| Идеи | система ≤ конец сентября 2026 |
| Сайт | ошибочная страница (дубликат МПТИ от 10.08.2026) — закрыть / заменить |

**Исключить из линейки:** П+CO₂, К+хладон/ФК, объёмы вне списка выше.

## 2. Структура дорожной карты (5 блоков)

Календарь от **18.08.2026** (вт):

```
БЛОК 1  18.08–24.08     Подготовка к презентации
БЛОК 2  25.08–28.08     Презентация линейки (+ запас до 31.08)
БЛОК 3  31.08–01.09     Совещание по продвижению (пн–вт)
БЛОК 4  01.09–30.09     Запуск продаж + система идей
БЛОК 5  01.10–31.12     Масштабирование → закрытие склада 200
```

Формат каждой задачи: **Задача | Роль | KPI (артефакт / срок)**.

---

### БЛОК 1. Подготовка к презентации  
**Срок:** 18.08 — 24.08.2026

| № | Задача | Роль | KPI |
|---|--------|------|-----|
| 1.1 | Исправить брошюру под утверждённую линейку (убрать П+CO₂ и К+хладон/ФК) | продукт + маркетинг | PDF-брошюра согласована до 24.08 |
| 1.2 | Закрыть ошибочную страницу сайта; черновик корректной карточки УГП-Авт | маркетинг + продукт | Ошибочная страница снята; черновик готов до 24.08 |
| 1.3 | Реестр 9 моделей: артикул, объём, масса ГОТВ, длина трубки | продукт + техподдержка | Таблица 9/9 полей заполнена или помечена «нет в паспорте» до 24.08 |
| 1.4 | Презентационные материалы (линейка, отличия П/К, сравнение с конкурентами) | продукт + маркетинг | Пакет слайдов готов до 24.08 |
| 1.5 | Шаблоны коммерческих предложений: П-Х, П-ФК, К-У | продажи + продукт | 3 шаблона КП готовы до 24.08 |
| 1.6 | Проект прайс-листа на утверждение | финансы + продажи + продукт | Проект прайса передан утверждающему до 24.08 |

**Критерий выхода из Блока 1:** брошюра + презентация + КП + реестр SKU готовы; сайт-ошибка закрыта.

---

### БЛОК 2. Презентация линейки  
**Срок:** 25.08 — 28.08.2026 (окно до 31.08)

| № | Задача | Роль | KPI |
|---|--------|------|-----|
| 2.1 | Провести презентацию для продаж, проектирования и желающих | продукт (ведёт); продажи / маркетинг / техподдержка (участники) | 1 проведённая сессия в окне 25–28.08; список участников зафиксирован |
| 2.2 | Q&A и сбор обратной связи | продукт + продажи | Протокол замечаний/вопросов в день презентации |
| 2.3 | Передача продукта в техподдержку | продукт → техподдержка | Акт передачи подписан; ответственный в техподдержке назначен |
| 2.4 | Публикация корректной страницы УГП-Авт | маркетинг | Страница online с линейкой П/К по коммюнике |

**Критерий выхода:** продукт передан техподдержке; материалы доступны продажам; страница не содержит старой линейки.

---

### БЛОК 3. Совещание по продвижению  
**Срок:** 31.08 — 01.09.2026 (пн–вт)

| № | Задача | Роль | KPI |
|---|--------|------|-----|
| 3.1 | Совещание: продажи, маркетинг, продукт, финансы | все указанные роли | Протокол с решениями до 01.09 |
| 3.2 | Выбор приоритетных сегментов из: ЦОД, нефтегаз, транспорт, склады | продажи + маркетинг + продукт | Утверждён приоритет сегментов на Q4 (список в протоколе) |
| 3.3 | Каналы: сайт, выставки, дилеры, тендеры — владельцы и действия | маркетинг + продажи | Матрица каналов с владельцем роли на каждый канал |
| 3.4 | План продаж Q4 2026 и Q1 2027 (шт. + выручка) | продажи + финансы | Утверждённый план в протоколе (цифры формируются на совещании, не заранее) |

**Критерий выхода:** есть протокол с приоритетами сегментов, каналами и планом Q4/Q1.

---

### БЛОК 4. Запуск продаж и система идей  
**Срок:** сентябрь 2026 (идеи ≤ 30.09.2026)

| № | Задача | Роль | KPI |
|---|--------|------|-----|
| 4.1 | Старт продаж по новой линейке | продажи | Первые отгрузки по утверждённым SKU; учёт в CRM/журнале |
| 4.2 | Обратная связь клиентов через техподдержку | техподдержка | Журнал обращений ведётся с 01.09 |
| 4.3 | Система сбора и хранения идей (1-я итерация) | продукт | Реестр идей работает не позднее 30.09 |
| 4.4 | Методика анализа рыночного потенциала идей (5 шагов) | продукт + маркетинг + финансы | Документ методики утверждён до 30.09 |

**Поля реестра идей:** название; источник; сегмент; потенциал 1–5; сложность 1–5; бюджет; приоритет; статус.

**Методика (5 шагов):** объём рынка → конкуренты → стоимость разработки → ROI → решение go/hold/kill.

**Критерий выхода:** продажи идут; ОС собирается; реестр идей + методика живы к 30.09.

### БЛОК 5. Масштабирование  
**Срок:** 01.10 — 31.12.2026

| № | Задача | Роль | KPI |
|---|--------|------|-----|
| 5.1 | Ежемесячная статистика отказов и вопросов | техподдержка + продажи | Дашборд за окт / нояб / дек |
| 5.2 | Адаптация КП под выбранные сегменты | продажи + маркетинг | КП по каждому приоритетному сегменту из Блока 3 |
| 5.3 | Профильные выставки | маркетинг + продажи | Факт участия или утверждённый план на 2027 |
| 5.4 | Рекламная кампания | маркетинг (+ финансы по бюджету) | Кампания запущена; лиды фиксируются |
| 5.5 | Закрытие склада | продажи | **200 шт. отгружено к 31.12.2026** |

**Критерий выхода:** выполнен план склада 200 шт.; каналная и сегментная модель работает; идеи питают бэклог 2027.

## 3. Сводный RACI (только дорожная карта)

| Процесс | Продукт | Техподдержка | Продажи | Маркетинг | Финансы |
|---------|---------|--------------|---------|-----------|---------|
| Брошюра / ТТХ / реестр SKU | A/R | C | I | R | I |
| Сайт УГП-Авт | C | I | I | A/R | I |
| Презентация и передача | A/R | R (приём) | C | C | I |
| Совещание / план Q4–Q1 | C | I | A/R | C | A |
| Продажи и отгрузки | C | C | A/R | C | C |
| Система идей | A/R | C | C | C | C |
| Реклама / выставки | C | I | C | A/R | C |
| KPI склада 200 | I | I | A/R | I | C |

R — исполняет; A — утверждает; C — консультирует; I — информируется.

---

## 4. Зависимости (критический путь)

```
Реестр SKU + брошюра + КП  →  Презентация  →  Передача в техподдержку
                                              ↓
                                    Совещание (сегменты/каналы/план)
                                              ↓
                         Продажи Q4  ←→  Идеи ≤30.09  →  Масштаб → 200 шт.
```

Без закрытия Блока 1 презентация тиражирует ошибочную линейку.  
Без Блока 3 нет утверждённого помесячного/квартального плана — только цель 200/год.

---

## 5. Что ещё «требует заполнения» до презентации

1. Артикулы и массы ГОТВ: П-Х-2, П-ФК-1/2, все К-У-*  
2. Длина трубки «в комплекте» / «макс.» по каждой модели (кроме 4 м у П-Х-1)  
3. Утверждённый прайс (сейчас: «не утверждены»; факт КП только на П-Х-1)  
4. Цифры плана Q4 2026 / Q1 2027 — только после Блока 3
