| Параметр | Значение |

## Как вставить в Mail.ru

1. Настройки → Имя и подпись → нужная подпись  
2. Кнопка «картинка» → загрузить файл  
3. Сделать ссылкой на: `https://pozhavt.ru/oborudovanie/ugp-avt-p/`
