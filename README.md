# HTML-шаблон письма МПТХ2 для Mail.ru

Светлый фирменный шаблон по стилю [pozhavt.ru/oborudovanie/mptkh2/](https://pozhavt.ru/oborudovanie/mptkh2/).

## Файл
`email-mptkh2.html`

## Стиль
- Цвета бренда: `#FF3333`, `#FFC309`, белый фон
- Структура как у страницы: шапка → описание → фото → ГОТВ → модули → характеристики → контроль → применение → ТКП
- Логотип PNG, картинки JPG
- Table 600px, инлайн-стили, mobile media queries

## Отправка
Вставьте HTML в письмо Mail.ru и отправьте тест.
