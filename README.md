# МПТХ2 — HTML-копия страницы

Самодостаточная HTML-страница по скрипту генерации копии [pozhavt.ru/oborudovanie/mptkh2/](https://pozhavt.ru/oborudovanie/mptkh2/).

## Файл

- `index.html` — полный документ (встроенные CSS + JavaScript, Font Awesome, SEO, формы, галерея, табы)

## Запуск

Откройте `index.html` в браузере или:

```bash
python3 -m http.server 8080
```

Затем: http://localhost:8080/
