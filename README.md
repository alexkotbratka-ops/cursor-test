# УГП-Авт — продуктовая страница

Страница автономных установок газового пожаротушения **УГП-Авт** по PDF-материалам (презентация + РЭ ПТДР.635165.036-П), в структуре как у МПТХ2.

## Открыть
- `ugp-avt.html` — основная страница
- `assets/ugp/` — изображения

```bash
python3 -m http.server 8080
```

http://localhost:8080/ugp-avt.html
