# МПТХ2 — адаптированная страница

Адаптация продуктовой страницы [МПТХ2](https://pozhavt.ru/oborudovanie/mptkh2/) с сохранением фирменного стиля.

## Улучшения
- Удобная sticky-навигация по разделам + мобильное меню
- Каталог модулей с фильтром по ЗПУ (12 / 32 / 50) и сортировкой
- Карточки продукции с кодом модели, объёмом и серией
- Чистая структура секций, кнопка «наверх», форма заявки

## Файлы
- `index.html`
- `adapt.css`
- `adapt.js`

```bash
python3 -m http.server 8080
```
