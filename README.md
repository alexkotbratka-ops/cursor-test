# Точная HTML-копия МПТХ2

Клон страницы [pozhavt.ru/oborudovanie/mptkh2/](https://pozhavt.ru/oborudovanie/mptkh2/).

Файл `index.html` — исходная разметка страницы с абсолютными ссылками на CSS, JS, шрифты и изображения оригинального сайта, чтобы внешний вид совпадал с оригиналом.

## Открыть

```bash
python3 -m http.server 8080
```

http://localhost:8080/

Или напрямую: [index.html в репозитории](https://github.com/alexkotbratka-ops/cursor-test/blob/cursor/mptkh2-product-page-04a0/index.html)
