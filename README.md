# МПТХ2 — страница продукта

HTML-версия страницы модулей газового пожаротушения МПТХ2 по материалам [pozhavt.ru/oborudovanie/mptkh2/](https://pozhavt.ru/oborudovanie/mptkh2/).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем перейдите на http://localhost:8080/
