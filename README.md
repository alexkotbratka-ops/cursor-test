# HTML-шаблон письма МПТХ2 для Mail.ru

Премиальный HTML email по странице [МПТХ2](https://pozhavt.ru/oborudovanie/mptkh2/).

## Файл
- **`email-mptkh2.html`** — основной шаблон для вставки в Mail.ru

## Что улучшено
- Настоящий логотип PNG (не SVG)
- Картинки в JPG — максимальная совместимость почтовых клиентов
- Яркий hero, цифры, ГОТВ, популярные модули, сравнение ЗПУ, объекты, сертификаты, сильный CTA
- Table-вёрстка 600px + инлайн-стили + mobile `@media` + VML-кнопки Outlook
- Публичные абсолютные URL ассетов

## Как отправить
1. Откройте `email-mptkh2.html` в браузере.
2. Вставьте HTML в письмо Mail.ru / сервис рассылок.
3. Отправьте тест себе на Mail.ru / Gmail / Яндекс.

```bash
python3 -m http.server 8080
```
