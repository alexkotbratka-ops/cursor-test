Типы установок

Два исполнения по способу подачи ГОТВ

УГП-Авт-П

Прямого действия

  • Подача ГОТВ по сенсорной трубке через отверстие
  • Тушение экранированных очагов
  • Ручной пуск: нет
  • ГОТВ: хладон 227еа, ФК-5-1-12
  • Защищаемый объём: 1–2 м³
  • Модули: 1 л, 2 л
  • Монтаж проще, стоимость ниже
УГП-Авт-К

Косвенного действия

  • Подача ГОТВ по выпускному трубопроводу с насадками
  • Равномерное распределение по объёму
  • Ручной пуск: да
  • ГОТВ: 227еа, ФК-5-1-12, CO₂
  • Защищаемый объём: 1–10 м³
  • Модули: 1 / 2 / 3 / 5 / 10 л
  • Сенсорная трубка до 50 м

Принцип действия

Тепловое обнаружение сенсорной трубкой и автоматическая подача ГОТВ

  1. Модуль с ГОТВ и запорно-пусковым устройством
  2. Кронштейн крепления
  3. Сенсорная трубка в зоне возможного возгорания
  4. Концевое устройство с индикатором давления
  5. Реле давления для сигнала во внешние цепи
  6. Для УГП-Авт-К — выпускной трубопровод и насадки

При нагреве трубка разрушается в зоне очага → автоматический пуск. Прямое действие: ГОТВ выходит через отверстие в трубке. Косвенное: ГОТВ идёт по трубопроводу через насадки.
